MercApp 🚀

Micrositio del proyecto desplegado (Unidad 3)

Resumen técnico

MercApp es una aplicación web SPA desarrollada con Vue 3 en el frontend y Node.js con Express en el backend. La base de datos se encuentra en MongoDB Atlas.

Arquitectura de despliegue

  • Frontend: Netlify
  • Backend: Railway
  • Base de datos: MongoDB Atlas
  • Documentación: GitHub Pages

Enlaces del proyecto

  • Frontend (Netlify)
  • API (Railway)
  • Repositorio GitHub

Ejecución local

git clone https://github.com/TU-USUARIO/TU-REPO.git # Backend cd backend npm install npm run dev # Frontend cd ../MercApp npm install npm run dev

Endpoints principales

Método Ruta Descripción
GET /api/health Verifica el estado de la API
GET /api/productos Obtiene todos los productos
POST /api/productos Crea un producto
GET /api/categorias Obtiene todas las categorías
POST /api/categorias Crea una categoría

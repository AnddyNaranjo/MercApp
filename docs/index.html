Proyecto Final: MercApp 🚀

Este es el micrositio de acceso directo al proyecto desarrollado para la Unidad 3.

🔗 Enlaces del Proyecto

  • Frontend (Netlify): frontmercapp.netlify.app ● Online
  • Backend API (Railway): mercapp-production-f1ce.up.railway.app ● Online

🛠️ Tecnologías utilizadas

📑 Endpoints de la API

  • GET /api/productos - Listar productos
  • GET /api/categorias - Listar categorías
  • GET /api/health - Estado del servidor
